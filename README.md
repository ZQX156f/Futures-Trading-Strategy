# TURNLAB · Batch-MCRNN

多品种商品期货「阶段性顶 / 底点」联合预测框架：用 **多尺度卷积（MS-CNN）+ 双注意力 LSTM** 把顶 / 底点预测建模为逐日二分类问题，12 个国内外农产品期货品种共享一套模型参数联合训练，输出交互式 HTML 分析报告（K 线图上直接标注预测顶 / 底，可切换 9 档置信度阈值）。

> 研究演示项目，不构成任何投资建议。



***

## 一、项目要解决的问题

期货交易中，识别 "阶段性高点 / 低点" 是加减仓操作的重要参考（高点附近常对应多单减仓或空单开仓，低点附近常对应空单减仓或多单开仓）。但顶 / 底点天然稀疏、形态不固定，难以用固定规则刻画。本项目尝试：



1. **标签**：用 RA-PLR 分段线性拟合从历史价格中自动提取转折点，构造高质量训练标签；

2. **模型**：用深度序列模型学习 "价格形态 + 量仓变化 + 技术指标 → 转折概率" 的映射；

3. **联合训练**：多品种共享同一套参数联合训练，让模型学习跨品种共性的转折形态，同时用品种嵌入保留个体差异。



***

## 二、核心原理

### 1. 标签体系：RA-PLR 转折点提取

**RA-PLR（Recursive Adaptive Piecewise Linear Regression，自适应分段线性回归）**



* **递归切分**：自顶向下把价格序列切成若干直线段 —— 初始为整段，每次取 "到拟合直线垂直距离最大" 的点作为新切分点，直到最大偏差 ≤ 拟合误差 δ；

* **自适应选 δ**：对 8 个候选误差（价格极差的 0.5%\~8%）分别做分段拟合，按「分段收益 − α × 短段惩罚」打分，自动选出最优 δ，避免人工调参；

* **转折点过滤（non-turn）**：只保留 "方向确实反转" 的极值点 —— 相邻三段涨跌符号相反、且反转幅度超过最小阈值，去掉噪声小波动；

* **波动自适应标签增强（augmented labeling）**：对每个转折点，按其邻域波动率加窗 —— 高波动行情 ±2 日、低波动行情 ±4 日，窗口内所有样本标为正类，避免 "一天一标签" 带来的过拟合与样本过稀。

> 标签只用历史数据生成，仅参与训练与评估，
>
> **不进入模型特征**
>
> ，杜绝标签泄漏。

### 2. 模型架构：Batch-MCRNN



```
MS-CNN（1D 卷积核 3/5/7，每尺度 6 通道）

&#x20;       │  ┌─ 残差相加（CNN 输出 + 原始输入 1×1 投影）

&#x20;       ↓

Fusion Embedding：拼接 8 维品种嵌入 → Linear(→ReLU→Dropout)

&#x20;       ↓

2 层 LSTM（hidden=48，BatchNorm + Dropout）

&#x20;       ↓

Temporal Attention（时间注意力）⊕ 残差 e = a + h\_T

&#x20;       ↓

Batch Attention（仅训练期：把 batch 维当序列做 4 头自注意力）

&#x20;       ↓

Linear → logit → sigmoid → P(该日为转折点)
```



* **MS-CNN**：1D 卷积核 {3, 5, 7} 并行提取短 / 中 / 长三种尺度的时间模式，same-pad 保持序列长度（输入为过去 24 个交易日）；

* **残差连接 ×3**（对应论文公式 H (x)=F (x)+x）：


  * CNN→Embedding：`cnn_out + Linear(原始输入)`；

  * LSTM→Attention：`e = a + h_T`（注意力加权和 ⊕ 最后时刻隐状态）；

  * BatchAttention：`LayerNorm(MSA(x) + x)`；

* **Temporal Attention**：`α_t = softmax(uᵀ·tanh(W·h_t + b))`，对 LSTM 各时刻输出加权求和，突出关键转折形态；

* **Batch Attention**：把 batch 维当作序列做 multi-head self-attention，让不同品种样本在训练时互相参照；**推理时用 weight-sharing 分类头直接前向，无 batch 依赖**，单条数据也可推理；

* **分类头**：单 Linear → logit，输出 sigmoid 概率。

### 3. 训练策略



* **多品种联合训练**：12 个品种（郑商所白糖 / 菜油 / 菜粕、大商所豆一 / 豆二 / 豆粕 / 豆油 / 棕榈油、CBOT 豆油 / 豆粕 / 大豆、ICE 11 号糖）的样本混合打乱，共享模型参数，品种嵌入负责区分；

* **严格时间切分**：训练段 5.5 年：测试段 1 年（train 与 val 合并为 train），按时间先后切分，测试段完全在训练段之后，无未来信息；

* **损失函数**：unweighted BCE（正负样本不设权重），单主路损失；

* **早停（拟合度优先）**：每 epoch 记录 train loss，连续 15 个 epoch 未刷新历史最低即停止（至少训练 20 epoch 防噪声早停），epoch 上限 300，最终模型取 **train loss 历史最低点**的权重；

* **特征标准化**：StandardScaler 仅用训练段拟合，再变换全量数据，避免测试信息流入。

### 4. 推理与顶 / 底判定



1. 模型对每个交易日输出转折概率 P ∈ \[0, 1]；

2. 概率 ≥ θ（阈值，提供 0.1\~0.9 共 9 档候选，报告默认 0.1）进入候选；

3. 候选日需在 **6 日窗内为极值**（当日收盘为窗内最高 → 顶，最低 → 底），即 "模型高概率 + 形态极值" 双重确认；

4. 在 K 线图上以 ▲（顶）/ ▼（底）标注，9 档阈值互斥单选，方便观察不同置信度下的信号密度。

全程只使用过去 24 个交易日的特征 + 当日数据，**无未来函数**。

## 三、数据与特征

输入为期货日线 xlsx/csv（OHLC + 成交量 + 持仓量），程序自动计算 16 维特征：



| 类别 | 特征                              |
| -- | ------------------------------- |
| 价格 | open / high / low / close       |
| 量仓 | volume /oi（持仓量）                 |
| 均线 | ma5 / ma10 / ma20               |
| 动量 | rsi(14) / roc5 / roc10 / mom5   |
| 形态 | amp（振幅）/vol\_chg（量比变化）/itk（阴阳线） |

数据不足时自动回填；同名多份文件自动挑选数据最完整、修改时间最新的一份。

## 六、输出报告（HTML）

生成的单文件 HTML 报告（ECharts 驱动，无需联网）包含：



1. **架构**：模型结构一览；

2. **切分与参数**：训练 / 测试区间、品种数、最佳 epoch、早停状态；

3. **汇总 KPI**：平均 / 合并（pooled）的 AUC、F1、MCC、精度、召回；

4. **分品种结果表**：每个品种的指标明细；

5. **训练曲线**：每轮 train loss + 最佳点标注 + 早停触发位置；

6. **测试集预测分布**：真实正样本 vs 预测正样本对比；

7. **K 线与预测点**：训练 / 测试分段着色、RA-PLR 拟合线、9 档阈值顶 / 底标记（图例互斥单选、可缩放）；

8. **方法与说明**：完整的方法学描述与免责声明。

## 七、示例运行结果

以下为最近一次运行（2026-09-14，12 品种，训练 2020-09\~2025-09，测试 2025-09\~2026-09）的实测指标，仅作展示：



| 汇总指标           | 值                            |
| -------------- | ---------------------------- |
| 平均 AUC         | 0.522                        |
| 平均 F1          | 0.606                        |
| 平均 MCC         | 0.019                        |
| 合并 AUC（pooled） | 0.524                        |
| 合并 F1（pooled）  | 0.634                        |
| 最佳 epoch       | 266（train loss 0.056，上限 300） |

分品种中表现较好的是郑商所白糖（AUC 0.665 / F1 0.877）、大商所豆油（AUC 0.623 / F1 0.722）等；部分品种接近随机。指标随数据与训练随机性波动，可重复运行观察分布。
